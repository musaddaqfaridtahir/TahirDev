# Musaddaq Farid Tahir - Developer Portfolio & Agency Site

A high-converting, state-of-the-art developer portfolio built with Next.js 15+ App Router, Tailwind CSS v4, and Lucide Icons.

## 🚀 GitHub & Vercel Deployment Instructions

### Option 1: Deploy on Vercel via GitHub (Recommended)

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Musaddaq Tahir Portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/musaddaq-portfolio.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Go to [Vercel Dashboard](https://vercel.com/new).
   - Import your `musaddaq-portfolio` GitHub repository.
   - Click **Deploy** (Vercel automatically detects Next.js build settings).

---

## 🛠️ Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Production Build Verification

```bash
npm run build
npm run start
```
